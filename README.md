# Accessibility Intelligence Platform --- Project Control Center

Working title: Accessibility Intelligence Platform Target: SIH 2026
Internal Hackathon --- Problem Statement #30

## Core hypothesis

Build venue-level accessibility intelligence: specific accessibility
attributes, exact venue/entrance location where relevant,
evidence/provenance, verification status, freshness, and personalized
discovery.

This is not merely a generic accessibility map or a single accessibility
score.

## Parallel work

-   Claude: accessibility data research and evidence collection
-   OpenCode #1: backend + database
-   OpenCode #2: frontend + UX
-   User: architecture, integration, AI/CV, verification, deployment,
    testing
-   Antigravity: independent non-conflicting research/QA

The `/docs` directory is the project's source of truth for plans,
decisions, schema, research, risks, and continuity.

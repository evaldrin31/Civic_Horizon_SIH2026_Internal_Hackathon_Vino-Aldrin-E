# MVP Scope

## Goal

Demonstrate that a user can discover a venue and inspect specific,
evidence-backed accessibility information.

## Must have

-   Venue search
-   Map/list discovery
-   Venue detail
-   Specific accessibility attributes
-   Exact location/entrance where relevant
-   Evidence/provenance
-   Verification status
-   Last observed/updated information
-   Basic personalized filtering
-   Report/correction flow
-   Real researched dataset

## Should have

-   Nearby search
-   Confidence
-   Contradiction handling
-   Evidence photos
-   Basic AI-assisted extraction

## Could have

-   Advanced computer vision
-   Route planning
-   Personalized profiles
-   Advanced analytics
-   Multi-city scaling

## Avoid in MVP

-   Generic chatbot as the primary feature
-   Huge feature list without reliable data
-   Unverified claims presented as facts
-   National-scale collection before proving the pipeline
-   Complex ML that does not improve the evidence problem

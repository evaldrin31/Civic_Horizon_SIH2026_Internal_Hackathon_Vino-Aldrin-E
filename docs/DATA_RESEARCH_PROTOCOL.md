# Data Research Protocol --- Claude

## Mission

Research, discover, extract, cross-check and structure real
accessibility information for later ingestion into the platform.

## Scope

Government, DEPwD/Accessible India/Sugamya Bharat, CSCs, banks/ATMs/BCs,
transport, hospitals, education, commercial venues, OSM/other permitted
datasets, existing accessibility platforms.

## Required record

-   venue
-   exact venue/location
-   attribute
-   value
-   specific location
-   source
-   source type
-   evidence
-   observation/collection date
-   verification state
-   confidence
-   limitations

## Non-negotiable

1.  Never fabricate.
2.  Do not treat missing evidence as NO.
3.  Preserve provenance.
4.  Distinguish reported/corroborated/verified.
5.  Flag conflicts.
6.  Record dates.
7.  Assess API/license/terms before recommending ingestion.
8.  Prefer authoritative sources.
9.  Clearly label uncertainty.

## Batch strategy

1.  Government
2.  CSC
3.  Banking/BC
4.  Transport
5.  Healthcare
6.  Education
7.  Commercial venues
8.  Existing datasets/platforms

Deliver research in batches so engineering can proceed in parallel.
